**Aegis** — это мощная, отказоустойчивая система для **параллельного объединения VPN-подписок** (VLESS, VMess, Shadowsocks, Trojan) в **единую 100% приватную ссылку** (GitHub Secret Gist) с защитой от ТСПУ, ультрабыстрым failover и интеллектуальным разделением трафика.

---

## ⚡ Ключевые возможности

- 🚀 **Параллельный асинхронный опрос (ThreadPoolExecutor):**
  - Подписки от всех провайдеров опрашиваются параллельно в несколько потоков в пределах 15-секундного тайм-аута, что ускоряет синхронизацию на ~70%.
- 🛡️ **Zero-Downtime отказоустойчивость:**
  - Если один из провайдеров упал (5xx, таймаут, блокировка), Aegis не падает с ошибкой, а выводит предупреждение и собирает рабочий конфиг из всех остальных здоровых источников.
- 🎯 **Дедупликация нод по фингерпринту (`server + port + uuid`):**
  - Исключает дубликаты прокси даже при наличии перекрывающихся подписок и разных названий у провайдеров.
- 📶 **5-уровневая иерархия Auto-Fallback:**
  - **Tier 1:** Финляндия 🇫🇮 и Швеция 🇸🇪 — минимальный физический пинг (~30–45 мс).
  - **Tier 2:** Транзитные мосты (`Москва → EU`) и ноды обхода DPI (`Обход`) — мгновенный failover для мобильного интернета (LTE) при работе ТСПУ и «белых списков».
  - **Tier 3:** Ядро ближней Европы: Германия 🇩🇪, Нидерланды 🇳🇱, Эстония 🇪🇪, Польша 🇵🇱, Латвия 🇱🇻, Литва 🇱🇹.
  - **Tier 4:** Остальная Европа и регион: Великобритания 🇬🇧, Франция 🇫🇷, Чехия 🇨🇿, Турция 🇹🇷, Казахстан 🇰🇿.
  - **Tier 5:** США 🇺🇸 и удаленные локации.
- 🧹 **Автоматическая очистка узлов:**
  - Полное удаление фиктивных псевдо-нод («Автовыбор», «LoadBalance»), сервисных заглушек (остаток трафика, техработы) и неэффективных российских серверов.
- 🤖 **Специализированная маршрутизация:**
  - `🤖 AI-Services` — Gemini, Claude, ChatGPT направляются через Tier-1 серверы США и Европы.
  - `🎬 Media-Streaming` — YouTube и SoundCloud через стриминговые ноды без потери битрейта.
  - `💬 Discord` — голосовые каналы (UDP xudp) и чаты без джиттера.
  - `✈️ Telegram` — европейские дата-центры Telegram.
  - `🎯 Games & Банки` — игры (Steam, Epic, Riot, Blizzard, EA), российские банки и Госуслуги идут **напрямую (`DIRECT`)**.
- 🔒 **100% Приватность через GitHub Secret Gist:**
  - Конфигурация деплоится исключительно в скрытый **Secret Gist** (`public: false`).
  - В открытом репозитории нет веток релиза (`release`), а все токены и UUID маскируются через `::add-mask::`.
- 🔐 **Строгая верификация TLS:**
  - Все запросы выполняются со строгой проверкой сертификатов (`verify=True`), защищая от атак MitM. Встроенный пре-коммит сканер (`scripts/check_diff.py`) предотвращает случайные утечки данных.

## 🚀 Быстрый старт за 2 минуты (В облаке GitHub)

GitHub Actions каждый час обновляет ваши ноды в облаке и сохраняет готовый конфиг в ваш персональный **Secret Gist**. Установка локального ПО **не требуется**.

```text
[1. Fork репозитория] ➔ [2. Добавить Секреты в Actions] ➔ [3. Запустить Action] ➔ [4. Вставить ссылку в клиент]
```

### Шаг 1. Сделайте Fork
Нажмите кнопку **`Fork`** в правом верхнем углу страницы репозитория, чтобы создать личную копию в своём GitHub-аккаунте.

### Шаг 2. Добавьте секреты в репозиторий
В вашем форке перейдите во вкладку:  
**Settings** ➔ слева выберите **Secrets and variables** ➔ **Actions**.

Добавьте секреты:

1. **`SUBSCRIPTIONS`** *(обязательно)*:
   - Нажмите **New repository secret**.
   - **Name:** `SUBSCRIPTIONS`
   - **Secret:** вставьте ссылки на ваши подписки (каждая с новой строки или в формате `Имя=URL`).
2. **`GIST_TOKEN`** *(обязательно)*:
   - Создайте токен в [GitHub Token Settings (Classic)](https://github.com/settings/tokens/new).
   - **Note:** `Aegis Gist Sync`
   - Отметьте одну галочку: **`gist`** (создание и редактирование гистов).
   - Нажмите **Generate token** и скопируйте токен.
   - В Secrets репозитория нажмите **New repository secret** ➔ **Name:** `GIST_TOKEN` ➔ вставьте токен ➔ сохраните.
3. **`GIST_ID`** *(опционально)*:
   - При первом запуске оставьте пустым — экшен создаст новый Secret Gist автоматически.
   - Затем скопируйте ID созданного гиста и добавьте секрет `GIST_ID`, чтобы экшен обновлял один и тот же гист.

### Шаг 3. Активируйте и запустите экшен
1. Перейдите во вкладку **Actions** в верхнем меню форка.
2. Если видите зеленый баннер **«I understand my workflows, go ahead and enable them»** — нажмите его.
3. В левой колонке выберите **Aegis Hourly Subscription Sync** ➔ нажмите **Run workflow** ➔ **Run workflow**.
4. Сборка займет 15–20 секунд.

### Шаг 4. Получите постоянную ссылку на Secret Gist
1. Откройте [gist.github.com](https://gist.github.com).
2. Вы увидите скрытую заметку **`Aegis — Smart Routing & Multi-Subscription Merger (100% Private)`**.
3. Откройте её и нажмите кнопку **`Raw`** над файлом `config.yaml`.
4. Удалите из адресной строки хэш коммита, чтобы получить **постоянную (unversioned)** ссылку, которая всегда отдает актуальную версию:
   ```text
   https://gist.githubusercontent.com/ВАШ_НИК/ID_ВАШЕГО_ГИСТА/raw/config.yaml
   ```

> 🔒 **Почему это на 100% безопасно:**  
> Secret Gist не отображается в вашем публичном профиле, не виден в поиске и недоступен сторонним пользователям без прямой ссылки. Ваши VLESS UUID и серверы никогда не попадут в открытый доступ.

## 📱 Инструкции по подключению клиентов

### Во FlClash (Android / iOS)
1. Откройте приложение **FlClash**.
2. В нижней панели перейдите во вкладку **«Профили» (Profiles)**.
3. Нажмите кнопку **«+»** в правом верхнем углу и выберите **«URL»** (или «Импорт по URL»).
4. Заполните поля:
   - **Название:** `Aegis`
   - **URL:** вставьте вашу постоянную ссылку на Secret Gist из Шага 4.
   - **Автообновление:** выберите интервал **`60 минут`** (1 час).
5. Нажмите **Сохранить**.
6. Нажмите на карточку созданного профиля, чтобы сделать его активным, вернитесь на главный экран и переключите тумблер **Старт**.

### В Clash Verge Rev (ПК: Windows / macOS / Linux)
1. Запустите **Clash Verge Rev**.
2. Перейдите во вкладку **«Профили» (Profiles)**.
3. В поле ввода в верхней части окна вставьте постоянную ссылку на Secret Gist.
4. Нажмите кнопку **«Импорт» (Import)**.
5. Нажмите правой кнопкой мыши по добавленному профилю `Aegis`:
   - Включите **«Автообновление»** с интервалом **`60 мин`**.
6. Выберите импортированный профиль левой кнопкой мыши.
7. Включите **Системный прокси (System Proxy)** или **TUN Режим (TUN Mode)** в левой панели.

## 💻 Локальный запуск на ПК

Если вы хотите запускать Aegis локально:

### 1. Подготовка
Требуется Python 3.9+.
```bash
git clone https://github.com/joiger/mihomo-smart-routing.git
cd mihomo-smart-routing
pip install -r requirements.txt
```

### 2. Настройка `config.json`
Скопируйте шаблон:
```bash
cp config.example.json config.json
```
Укажите ссылки на подписки в `config.json`.

### 3. Запуск
- **Windows (разовый запуск):** двойной клик по `update.bat`.
- **Windows (ежечасное обновление в фоне):** запустите `schedule_hourly.bat` (регистрирует задачу `AegisSmartRoutingSync` в Планировщике Windows через `pythonw.exe`).
- **Linux / macOS:** запустите `./schedule_hourly.sh` (добавляет задачу в `crontab`).
- **Режим службы (Daemon):** `python sync.py --interval 1`.

## 🛡️ Безопасность и аудит

- **Zero Git Leaks:** Все промежуточные данные и выходные конфигурации изолированы в `.gitignore`.
- **Pre-Commit Scanner:** Скрипт `scripts/check_diff.py` автоматически проверяет коммиты и diff на отсутствие персональных доменов (`*.desiderius.ru`) и токенов.
- **Маскирование в CI:** Все приватные параметры маскируются через `::add-mask::` в логах GitHub Actions.
