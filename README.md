Универсальный инструмент для **объединения нескольких VPN-подписок** (VLESS, VMess, Shadowsocks, Trojan) в **единую автообновляемую ссылку** с защитой от ТСПУ и интеллектуальным разделением трафика.

---

## ⚡ Ключевые возможности:

- 🔀 **Объединение любых подписок:** склеивает ссылки разных провайдеров в один конфигурационный файл, исключает дубликаты, автоматически обходит защитные Nginx-куки (307 redirect) и эмулирует корректные User-Agent.
- 🧹 **Очистка от мусора и псевдо-узлов:** автоматически вырезает неработающие псевдо-ноды «Автовыбор» (`🌐 Автовыбор`, `⚡ Авто-выбор`), заглушки техработ, информационные сообщения и неэффективные российские узлы.
- 🛡️ **Анти-ТСПУ и бесшовный роуминг Wi-Fi ↔ LTE:**
  - **Ультрабыстрый Failover (20 сек):** ядро проверяет доступность каждые 20 секунд с таймаутом 2.5 секунды в непрерывном режиме (`lazy: false`). При выходе из дома телефон не зависает на 5 минут при блокировке foreign IP.
  - **Умная иерархия:** сначала быстрые узлы с минимальным пингом (Финляндия 🇫🇮, Швеция 🇸🇪 ~30–45 мс), затем защищённые транзитные мосты (`Москва → Германия/Нидерланды`, `Обход`), гарантированно работающие в мобильных «белых списках».
  - **Мгновенный сброс разорванных сокетов:** флаги `strict-route`, `auto-detect-interface` и `keep-alive-interval: 15` исключают эффект «чёрной дыры» при смене сети.
  - **Выделенная группа `🛡️ Mobile-Bypass`:** для ручной фиксации на транзитных мостах при сильных мобильных глушилках.
- 🤖 **`AI-Services`** — Gemini, Claude, OpenAI/ChatGPT автоматически направляются через Tier-1 серверы США и Европы (без ошибок региона).
- 🎬 **`Media-Streaming`** — YouTube и SoundCloud идут через выделенные стриминг-узлы без буферизации.
- 💬 **`Discord`** — голосовые каналы (UDP) и медиа работают стабильно без потерь пакетов.
- ✈️ **`Telegram`** — быстрая отправка файлов через европейские дата-центры Telegram.
- 🎯 **`Games & Банки`** — игры (Steam, Epic, Riot, Blizzard, EA), российские банки и Госуслуги идут **напрямую (`DIRECT`)** с минимальным пингом.
- 🔒 **Защищённый DNS:** гибридная схема Fake-IP: отечественные зоны (`.ru`, `.su`, `.рф`) разрешаются через Yandex DNS, а зарубежные запросы — через шифрованный Google DoH.

## 🚀 Быстрый старт за 2 минуты (В облаке GitHub)

> **Идеально для Android (FlClash) и ПК (Clash Verge Rev).**  
> GitHub Actions каждый час обновляет ваши ноды в облаке и публикует свежий конфиг по секретной ссылке. Установка Python на ПК или телефон **не требуется**.

```
[1. Fork репозитория] ➔ [2. Добавить SUBSCRIPTIONS и GIST_TOKEN] ➔ [3. Запустить Action] ➔ [4. Вставить ссылку Gist в клиент]
```

### Шаг 1. Сделайте Fork
Нажмите кнопку **`Fork`** в правом верхнем углу этой страницы, чтобы создать личную копию репозитория в своём GitHub-аккаунте.

### Шаг 2. Добавьте секреты в репозиторий
1. В вашем форке перейдите во вкладку **Settings** ➔ слева выберите **Secrets and variables** ➔ **Actions**.
2. Добавьте секрет **`SUBSCRIPTIONS`**:
   - Нажмите **New repository secret**.
   - **Name:** `SUBSCRIPTIONS`
   - **Secret:** вставьте ссылки на ваши подписки (каждая ссылка с новой строки).
3. Добавьте секрет **`GIST_TOKEN`** (для создания скрытого Secret Gist):
   - Откройте в новой вкладке [GitHub Token Settings (Classic)](https://github.com/settings/tokens/new).
   - В поле **Note** напишите `Mihomo Sync`.
   - Отметьте одну галочку: **`gist`** (создание скрытых гистов).
   - Нажмите **Generate token** и скопируйте полученный токен (начинается с `ghp_`).
   - Вернитесь в настройки секретов репозитория ➔ нажмите **New repository secret** ➔ Name: `GIST_TOKEN` ➔ вставьте токен ➔ нажмите **Add secret**.

### Шаг 3. Активируйте и запустите генерацию
1. Перейдите во вкладку **Actions** в верхнем меню вашего форка.
2. ⚠️ **Первый запуск:** Если видите зеленый баннер **«I understand my workflows, go ahead and enable them»** — **нажмите её**.
3. В левой колонке выберите **Hourly Subscription Sync** ➔ нажмите **Run workflow** ➔ **Run workflow**.
4. Экшен за 20 секунд автоматически создаст ваш персональный **Secret Gist** и зальет туда готовый конфиг.

### Шаг 4. Получите вашу 100% приватную ссылку
1. Откройте [gist.github.com](https://gist.github.com) (вкладка со всеми вашими гистами).
2. Вы увидите свежую скрытую заметку **`Mihomo Smart Routing Config (100% Private)`**.
3. Нажмите на неё ➔ нажмите кнопку **`Raw`** над файлом `config.yaml`.
4. Скопируйте URL из адресной строки браузера и удалите из него хэш коммита (чтобы ссылка всегда отдавала последнюю версию):
   ```text
   https://gist.githubusercontent.com/ВАШ_НИК/ID_ВАШЕГО_ГИСТА/raw/config.yaml
   ```
> 🔒 **Почему это на 100% безопасно:**  
> Скрытые гисты (`Secret Gist`) **не видны** в вашем публичном профиле, не привязаны к дереву форков репозитория и не индексируются поисковиками. Ни один человек в интернете не сможет подсмотреть ваши VLESS-ключи.

### Шаг 5. Подключите клиент
- **Во FlClash (Android / iOS):**
  1. Откройте приложение, перейдите в нижнюю вкладку **«Профили» (Profiles)**.
  2. Нажмите **«+»** в правом верхнем углу ➔ выберите пункт **«URL»** (или «Импорт по URL»).
  3. Вставьте вашу постоянную ссылку на Secret Gist из Шага 4.
  4. В строке **«Автообновление»** укажите **`60 минут`** (1 час).
  5. Нажмите **Сохранить**, выберите скачанный профиль и нажмите кнопку **Старт** на главном экране.
- **В Clash Verge Rev (ПК):**
  1. Откройте **«Профили»** ➔ вставьте ссылку на Gist в поле ввода вверху ➔ нажмите кнопку **«Импорт»**.
  2. Нажмите правой кнопкой мыши по добавленному профилю ➔ включите ежечасное автообновление.

## 💻 Локальный запуск на ПК

Если вы хотите запускать генератор локально на своей машине без использования GitHub Actions:

### 1. Подготовка
Требуется Python 3.9+. Склонируйте репозиторий и установите зависимости:
```bash
git clone https://github.com/joiger/mihomo-smart-routing.git
cd mihomo-smart-routing
pip install -r requirements.txt
```

### 2. Настройка `config.json`
Скопируйте шаблон:
```bash
cp config.example.json config.json
```
Вставьте ваши ссылки в `config.json`.

### 3. Запуск
- **Windows (разовый запуск):** двойной клик по `update.bat`.
- **Windows (фоновое автообновление каждый час):** запустите `schedule_hourly.bat` — скрипт добавит задачу в Планировщик Windows (работает тихо в фоне через `pythonw.exe` без консольных окон).
- **Linux / macOS:** запустите `./schedule_hourly.sh` (добавит задачу в `crontab`).
- **Режим службы (Daemon):** `python sync.py --interval 1`.

Готовый профиль автоматически сохранится в вашу папку **Загрузки (`~/Downloads/3-in-1_VPN.yaml`)**.

## 🔒 Безопасность и приватность

- **100% защита исходных подписок:** Ваши реальные провайдерские токены и URL хранятся исключительно в зашифрованных `GitHub Encrypted Secrets` и никогда не попадают в историю коммитов или публичные логи.
- **Защита от перебора ссылок:** Итоговый файл в ветке `release` содержит криптографический SHA-256 токен (32 шестнадцатеричных символа, $16^{32} \approx 3.4 \times 10^{38}$ комбинаций), что делает его подбор перебором вычислительно невозможным.
- **CDN-кэширование:** Серверы `raw.githubusercontent.com` кэшируют ответы на 5 минут (`TTL 300s`). Для ежечасного автообновления это совершенно прозрачно.
- **Полная изоляция:** Если вам принципиально не хочется использовать сторонние облака — используйте **локальный режим** запуска на собственном ПК/сервере.
