# Learning Proposal: Сохранение файлов в Загрузки (Downloads) вместо Рабочего стола (Desktop)

## 1. Классификация
* **Тип:** Пользовательское правило поведения (User Preference Rule).
* **Файл для обновления:** `C:\Users\hitsugi ni ochita\.gemini\config\rules\user_preferences.md`
* **Обоснование:** Это строгое постоянное поведенческое ограничение (guardrail) для файловых операций: не засорять Рабочий стол, а отправлять сгенерированные файлы (конфиги, дампы, архивы) в папку `Downloads`.

     * Любые сгенерированные для пользователя выходные файлы (конфигурации VPN, экспорты, скомпилированные пакеты, архивы, дампы) сохранять строго в папку **«Загрузки» (`C:\Users\hitsugi ni ochita\Downloads`)**, а **НЕ на Рабочий стол (`Desktop`)**. Рабочий стол пользователя должен оставаться чистым.
