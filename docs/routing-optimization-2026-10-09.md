# Настройка стабильности и скорости — 9 октября 2026

Изменения применены к работающему Clash через API Mihomo. TUN и смешанный порт 7897 сохранились. Полный список из 48 узлов сохранён; активные соединения принудительно не закрывались. Резервные копии конфигурации и прежнего скрипта находятся рядом с оригиналами в каталоге Clash Verge.

## Измерения

Проведено по три проверки `gstatic/generate_204` для каждого из 48 узлов, параллелизм ограничен четырьмя запросами. 22 узла прошли 3/3 проверки, один — 2/3, остальные — 0/3. Неудача сейчас не означает постоянную недоступность, поэтому узлы не удалены.

Для восьми кандидатов проведены по две загрузки по 2 МиБ через временный отдельный экземпляр Mihomo, привязанный к физическому интерфейсу Ethernet. Проверка TLS включена. Временный экземпляр завершён, файл с копиями параметров прокси удалён.

## Политика маршрутизации

- Основной пул: Финляндия VPNUS, Швеция LockAway, Обход 2.1 Artemida, Швеция VPNUS, Германия VPNUS. Три разных поставщика снижают зависимость от одного сервиса, но не гарантируют независимость их инфраструктуры.
- `Auto-Fallback`: пять основных узлов и ссылка на полный резерв; проверки через 30 секунд.
- `Mobile-Bypass`: небольшой пул с приоритетом обходного реле; ленивые проверки через 60 секунд. Работа на мобильной сети отдельно не измерялась.
- `Auto-UrlTest`: пять узлов, интервал 60 секунд, порог переключения 100 мс, ленивые проверки.
- AI сохраняет американский выход первым, чтобы не менять рабочую сессию по результатам только транспортного теста. Увеличен таймаут проверки до 5 секунд.
- Добавлены отдельные группы проверки Antigravity, Claude и OpenAI с ожидаемыми ответами 404/404/401. Точные правила API стоят до общих AI-правил, после локальных исключений Unlocker. Такие ответы подтверждают доступность HTTP API, но не авторизованную генерацию или доступность аккаунта в регионе.
- Полные резервные пулы проверяются лениво. Все узлы доступны также через прежние ручные селекторы.

## Телеметрия и сохранение настроек

Геоблокировка больше не удерживает штраф семь дней. Он действует 15 минут в конкретной категории и сети; успешная более поздняя проверка снимает его раньше. Обычный таймаут не считается доказательством снятия геоблокировки. Это механизм пересчёта при получении новых измерений, а не отдельный автоматически запущенный сборщик телеметрии.

Локальный порядок узлов сохранён в игнорируемом Git файле `config.local.json`. Генератор читает его поверх параметров маршрутизации. SQLite телеметрия также исключена из Git.

Скрипт `scripts/verge_routing.js` установлен в связанный скрипт активного профиля Clash Verge; он повторяет оптимизацию при будущих обновлениях подписки. Локальный установленный вариант содержит измеренный порядок узлов. Версия в репозитории содержит общие настройки без персональных параметров.

Проверено сохранение всех узлов в резерве, отсутствие циклов, повторное применение без изменений, приоритет локальных правил и совпадение Python-генератора со скриптом Verge. Все 29 основных тестов, 5 тестов телеметрии и 6 тестов диагностики прошли.

## Ограничения

Внешние серверы Opera и встроенные резервные выходы Unlocker не восстановлены этой настройкой. Изменения не отключают проверку TLS и не запускают Nova одновременно с TUN Clash. Подтверждать качество AI-пула нужно также результатами реальных запросов моделей; данные короткой сетевой проверки для этого недостаточны.
